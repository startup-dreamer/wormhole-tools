The wormcraft CLI

Query, parse, and interact with the Wormhole cross-chain protocol — plus a full deploy pipeline for cross-chain contracts.

Get started View commands

Requires Node.js 18+

$ npm install -g wormcraft

Quick start

After installing, create a config file and run your first command:

# Create config directory and .env
mkdir -p ~/.wormcraft
cat > ~/.wormcraft/.env << EOF
WORMCRAFT_ETHEREUM_RPC=https://mainnet.infura.io/v3/YOUR_KEY
WORMCRAFT_ARBITRUM_RPC=https://arb-mainnet.g.alchemy.com/v2/YOUR_KEY
EOF

# Explore supported chains
wormcraft info chains

# Look up a VAA by transaction hash
wormcraft status --chain ethereum --tx 0xabc123...

# Parse a VAA hex string
wormcraft parse 010000000001...

Deploy pipeline

wormcraft deploy ships and upgrades contracts cross-chain via the WormcraftDeployer hub contract. Three governance modes are supported.

Upgrade — direct (WormcraftProxy inheritance)

wormcraft deploy upgrade --proxy $PROXY --new-impl $IMPL --chains sepolia

Upgrade — via Gnosis Safe module

wormcraft deploy upgrade --proxy $PROXY --new-impl $IMPL --chains sepolia \
  --safe $SAFE --module $WORMCRAFT_MODULE

Upgrade — via WormcraftAdminModule (no inheritance, optional timelock)

wormcraft deploy upgrade --proxy $PROXY --new-impl $IMPL --chains sepolia \
  --admin-module $ADMIN_MODULE --salt my-upgrade-salt

Execute a timelocked upgrade after the delay

wormcraft deploy execute \
  --proxy $PROXY --new-impl $IMPL --chains sepolia \
  --admin-module $ADMIN_MODULE --salt my-upgrade-salt

Generate Safe Transaction Builder JSON for module setup

wormcraft module setup \
  --safe $SAFE --module $WORMCRAFT_MODULE \
  --source-chain 10002 --authorized $WALLET

Configuration

All config lives in ~/.wormcraft/.env. RPC endpoints follow a single consistent pattern: 

# Pattern: WORMCRAFT_{CHAIN_TICKER}_RPC
WORMCRAFT_ETHEREUM_RPC=https://mainnet.infura.io/v3/YOUR_KEY
WORMCRAFT_ARBITRUM_RPC=https://arb-mainnet.g.alchemy.com/v2/YOUR_KEY
WORMCRAFT_BASE_RPC=https://mainnet.base.org
WORMCRAFT_OPTIMISM_RPC=https://mainnet.optimism.io
WORMCRAFT_POLYGON_RPC=https://polygon-rpc.com
# Testnets — use underscores for hyphenated chain names
WORMCRAFT_SEPOLIA_RPC=https://ethereum-sepolia.publicnode.com
WORMCRAFT_ARBITRUM_SEPOLIA_RPC=https://sepolia-rollup.arbitrum.io/rpc
WORMCRAFT_BASE_SEPOLIA_RPC=https://sepolia.base.org

Add whichever chains you need — any WORMCRAFT_*_RPC variable is picked up automatically.

VariableDescription
WORMCRAFT_PRIVATE_KEYDeployer private key (0x-prefixed hex)
WORMCRAFT_ETHERSCAN_KEYEtherscan API key for contract verification
WORMCRAFT_NETWORKmainnet or testnet (default: mainnet)

SDK

All CLI functionality is also available as a TypeScript library. Requires Node.js 20+.

# Install the SDK
npm install @wormcraft/sdk
import {
  parseVaa, getMessageStatus, MessageStatus,
  EvmChain, deployAcrossChains, upgradeAcrossChains,
} from "@wormcraft/sdk";

// Parse a VAA (hex or base64)
const vaa = parseVaa("0x010000000001...");
console.log(vaa.emitterChain, vaa.sequence);

// Track message status
const result = await getMessageStatus({ emitterChain: 2, emitterAddress, sequence: 643990n });
if (result.status === MessageStatus.Signed) console.log("VAA ready", result.vaaBytes);

// EVM chain adapter (viem)
const eth = new EvmChain({ chainId: 2n, chainName: "ethereum", rpcUrl: process.env.WORMCRAFT_ETHEREUM_RPC });
