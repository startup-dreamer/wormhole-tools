The worm-tool CLI

Query, parse, and interact with the Wormhole cross-chain protocol — plus a full deploy pipeline for cross-chain contracts.

Get started View commands

Requires Node.js 18+

$ npm install -g worm-tool

Quick start

After installing, create a config file and run your first command:

# Create config directory and .env
mkdir -p ~/.worm-tool
cat > ~/.worm-tool/.env << EOF
WORM_TOOL_ETH_RPC=https://mainnet.infura.io/v3/YOUR_KEY
WORM_TOOL_SOL_RPC=https://api.mainnet-beta.solana.com
EOF

# Explore supported chains
worm-tool info chains

# Look up a VAA by transaction hash
worm-tool status --chain ethereum --tx 0xabc123...

# Parse a VAA hex string
worm-tool parse 010000000001...

Deploy pipeline

worm-tool deploy ships your contract to every chain from a single YAML manifest. Deployments are deterministic — the same address on every chain — thanks to CREATE2 via WormToolDeployer.

1. Initialize a manifest

worm-tool deploy init
# Creates worm-tool.deploy.yaml in the current directory

2. Edit the manifest

# worm-tool.deploy.yaml
version: "1"
contracts:
  MyToken:
    artifact: out/MyToken.sol/MyToken.json  # Foundry
    salt: my-token-v1
    chains: [ethereum, arbitrum, base, optimism]
    constructorArgs:
      - "${DEPLOY_OWNER}"          # env-var interpolation

3. Check & preview

# Run pre-deployment health checks
worm-tool doctor

# Preview what will be deployed (no transactions)
worm-tool deploy plan

# Diff storage layout vs previous version (upgrades)
worm-tool deploy diff MyToken

4. Deploy

# Dry-run: simulate without sending transactions
worm-tool deploy run --dry-run

# Live deploy to all chains in the manifest
worm-tool deploy run

# Upgrade-safe: validates storage layout before upgrading
worm-tool deploy upgrade-safe MyToken

5. Verify on Etherscan

worm-tool deploy verify MyToken --chain ethereum

Configuration

All config lives in ~/.worm-tool/.env. Every variable is prefixed WORM_TOOL_.

VariableDescription
WORM_TOOL_ETH_RPCEthereum JSON-RPC URL
WORM_TOOL_ARB_RPCArbitrum JSON-RPC URL
WORM_TOOL_BASE_RPCBase JSON-RPC URL
WORM_TOOL_OPT_RPCOptimism JSON-RPC URL
WORM_TOOL_SOL_RPCSolana RPC URL
WORM_TOOL_PRIVATE_KEYDeployer private key (hex, no 0x prefix)
WORM_TOOL_ETHERSCAN_KEYEtherscan API key for contract verification
WORM_TOOL_NETWORKmainnet or testnet (default: mainnet)

You can also pass --testnet to most commands to override the network for that invocation.

SDK

All CLI functionality is also available as a TypeScript library:

# Install the SDK
npm install @worm-tool/sdk
import { getChainInfo, parseVaa, getMessageStatus } from "@worm-tool/sdk";

// Look up chain metadata
const chain = getChainInfo("ethereum");
console.log(chain.wormholeChainId); // 2

// Parse a VAA
const vaa = parseVaa(hexString);
console.log(vaa.emitterChain, vaa.sequence);

// Check message delivery status
const status = await getMessageStatus({ chain: "ethereum", txHash });
console.log(status.delivered); // true | false | "pending"
